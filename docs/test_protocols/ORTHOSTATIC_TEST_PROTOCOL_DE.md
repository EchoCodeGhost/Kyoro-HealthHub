# Verlängerter Schellong-Test / 10-Minuten-NASA-Lean-Test — Heimprotokoll

> **English version:** [ORTHOSTATIC_TEST_PROTOCOL.md](ORTHOSTATIC_TEST_PROTOCOL.md)

**Zweck:** POTS-Screening bei Verdacht auf orthostatische Intoleranz.
Formales POTS-Kriterium: ΔHR ≥ 30 bpm innerhalb 10 Minuten Stehen (Raj et al., 2021).
Dieses Protokoll folgt dem Zeitschema des **10-Minuten-NASA-Lean-Test**
(Bateman Horne Center) — dem in der ME/CFS-/POTS-Diagnostik standardisierten,
validierten Verfahren, das über die klassischen 2–3 Minuten des einfachen
Schellong-Tests hinausgeht (Quellen am Ende des Dokuments).

---

## Was du brauchst

| Gerät | Wofür |
|---|---|
| Brustgurt-HR-Monitor (z.B. Polar H10) | Beat-to-Beat HR, lückenlos |
| Aufzeichnungs-App fürs Handy | HR-Aufzeichnung starten |
| Blutdruckmessgerät (beliebig) | RR liegend + stehend |
| Timer (Handy) | 10-Minuten-Countdown |
| Wand zum Anlehnen | Stabilität beim Stehen |
| Notizbuch oder App | Werte mitschreiben |
| Ruhige Begleitperson (**nicht optional**) | Sicherheit bei Schwindel/Synkope, bedient ggf. die Geräte, schreibt Werte mit |

**Geräteagnostisch:** Das Protokoll funktioniert mit jedem Blutdruckmessgerät,
das RR+Puls auf Knopfdruck liefert (z.B. Omron X7 Smart) — jede Messung
einfach einzeln auslösen. Besitzt du ein Gerät mit **automatischer
Serienmessung** (z.B. Withings BPM Core: "Advanced Mode"/START-3, deckt bei
1-Minuten-Intervall bis zu 3 der Messzeitpunkte mit einem Tastendruck ab —
[Anleitung](https://support.withings.com/hc/en-us/articles/360024351713-BPM-Core-Enabling-the-advanced-mode)),
kannst du das nutzen, um Tastendrücke zu sparen — Voraussetzung ist nur,
dass du prüfst, ob dein Gerät die Einzelmessungen mit eigenem Zeitstempel
speichert/exportiert oder nur den Durchschnitt (dann lieber aus der
Live-Anzeige mitschreiben statt sich auf den Export zu verlassen).

**Warum Brustgurt statt Manschette für den Puls:** Manschetten-Blutdruck-
geräte messen den Puls bei starken, schnellen Schwankungen — wie sie
genau beim Aufstehen auftreten — oft ungenau. Für die eigentliche
Pulserfassung ist ein Brustgurt, Fingerpulsoximeter oder eine Smartwatch/
Puls-App zuverlässiger; die Manschette wird nur für die Blutdruckwerte
selbst gebraucht.

## Vorbereitung

- **Uhrzeit:** Morgens, 30–60 Min nach dem Aufstehen — NICHT direkt nach dem Aufstehen
  (Cortisol-Peak verfälscht Baseline). Ideal: 09:00–11:00 Uhr.
- **Kein Koffein** in den 2h davor
- **Kein Sport** in den 4h davor
- **Gut hydriert:** 500 ml Wasser ca. 30 Min vor dem Test trinken
  (Hypovolämie ist häufige POTS-Ursache, Hydration reduziert falsch-positive Befunde nicht,
  erhöht aber die Reproduzierbarkeit)
- **Warme Umgebung:** Kälte verursacht Vasokonstriktion und verfälscht HR-Antwort
- **Kein Essen** 2h davor (Postprandiale Hypotonie kann POTS-ähnliches Muster erzeugen)
- **Keine Kompressionsstrümpfe** tragen — sie verändern die orthostatische
  Reaktion und verfälschen das Ergebnis
- **Medikamente/Substanzen:** Manche Medikamente und Substanzen (z. B.
  Blutdruckmittel, Stimulanzien inkl. Koffein, trizyklische
  Antidepressiva) verändern die Werte. Ob eine Einnahmepause vor dem Test
  sinnvoll und möglich ist, vorab ärztlich klären — verschreibungspflichtige
  Medikation nicht eigenmächtig pausieren

## Durchführung

### Phase 1: Hinlegen (10 Minuten)

1. HR-Monitor anlegen, Aufzeichnung starten
2. Flach hinlegen (kein Kissen unter dem Kopf), Beine gestreckt
3. **10 Minuten still liegen** — nicht sprechen, nicht Handy bedienen
4. In Minute 9–10: Blutdruck messen (liegend)
5. HR-Werte merken/notieren

**Notieren: HR liegend (Mittel der letzten 2 Min), RR liegend**

### Phase 2: Aufstehen und Stehen (10 Minuten)

6. Ruhig aufstehen — **nicht schnell, kein Abdrücken mit den Armen**
7. An die Wand lehnen — **Fersen ca. 15–20 cm von der Wand entfernt**,
   Schulterblätter berühren die Wand (offizielle NASA-Lean-Test-Haltung,
   Bateman Horne Center). Alternative: direktes Vollanlehnen (Kopf, Rücken,
   Fersen an der Wand) verhindert Muskelkontraktionen der Beine noch etwas
   zuverlässiger, ist aber nicht die Haltung, mit der die publizierten
   NASA-Lean-Test-Referenzwerte erhoben wurden — bei Vergleichbarkeit mit der
   Literatur die 15–20-cm-Variante wählen.
8. Timer starten

**Messen und notieren:**

| Zeitpunkt | HR | RR | Symptome |
|---|---|---|---|
| Stehen 0 Min (sofort) | | | |
| Stehen 1 Min | | | |
| Stehen 2 Min | | | |
| Stehen 3 Min | | | |
| Stehen 5 Min | | | |
| Stehen 7 Min | | | |
| Stehen 10 Min | | | |

**Symptome dokumentieren:** Schwindel, Herzklopfen, Sehstörungen,
Blässe, Übelkeit, Schwäche, Kopfschmerz — und zu welchem Zeitpunkt.

### Phase 3: Hinlegen (Erholung)

9. Hinlegen
10. HR nach 2 Min notieren — wie schnell erholt sich die HR?

## Auswertung

### POTS-Kriterium (Raj et al., 2021)
**ΔHR ≥ 30 bpm** innerhalb von 10 Minuten Stehen **ohne orthostatische Hypotonie**

### Orthostatische Hypotonie
**RR-Abfall ≥ 20 mmHg systolisch oder ≥ 10 mmHg diastolisch** innerhalb 3 Min Stehen
(das wäre eine andere Diagnose als POTS)

### Graubereiche
- ΔHR 20–29 bpm: orthostatische Intoleranz ohne formales POTS — klinisch relevant
- HR > 120 bpm im Stehen: auch ohne ΔHR ≥ 30 POTS-kompatibel (wenn Symptome)

## Warum ein 2-Minuten-Schnelltest oft zu kurz greift

Viele Kurzprotokolle testen nur 2–3 Minuten Stehen. Das kann falsch-negativ sein:

- Viele Betroffene brauchen 5–10 Minuten für den maximalen HR-Anstieg
- Arme nicht angelehnt: Muskelkontraktionen dämpfen den HR-Anstieg
- Tageszeit und Hydration beeinflussen das Ergebnis erheblich (s. Vorbereitung oben)
- Laut Bateman Horne Center reichen **mindestens 5 Minuten** Stehzeit, um bei
  den meisten Patient:innen ein orthostatisches Intoleranz-Muster zu
  erfassen — die vollen 10 Minuten dieses Protokolls erfassen mehr

**Mehrfach testen:** POTS-Schweregrad variiert mit Tageszeit, Hydration, Hormonstatus, Schlaf, Wärme.
Mindestens 3 Tests an verschiedenen Tagen für eine belastbare Aussage.

## Für den Kardiologen / Neurologen

Diese Ergebnisse mitbringen:
- HR-Rohdaten (RR-Intervall-Zeitreihe, falls per Brustgurt aufgezeichnet)
- Blutdruckwerte (liegend + stehend, mehrere Zeitpunkte)
- Symptom-Zeitstempel
- Ergebnisse mehrerer Heimtests, falls vorhanden

Kipptisch-Test in der Klinik (70°-Kippung, 45 Minuten) ist der Goldstandard —
kann nach positivem Heim-Schellong angefordert werden.

---

## Sicherheitshinweis

Während des Tests kann es zu Schwindel bis hin zu Ohnmacht (Synkope)
kommen. **Führe den Test grundsätzlich nur mit einer Begleitperson durch**
— sie bedient bei Bedarf die Geräte, schreibt die Werte mit und kann im
Notfall eingreifen, während du selbst ruhig und entspannt an der Wand
stehst.

Bei starkem Schwindel, Sehschwäche, Blässe oder Ohnmachtsgefühl:
**sofort hinlegen**, Beine hochlagern. Test abbrechen und erst nach vollständiger
Erholung (>30 Min) fortsetzen.

**Bei ME/CFS:** Der Test selbst kann eine PEM-Zustandsverschlechterung
auslösen — plane danach bewusst Erholungszeit ein, statt direkt im
Anschluss weitere Termine oder Belastung einzuplanen.

Für dieses volle Protokoll (HR + SpO2 + Blutdruck an allen Zeitpunkten
0/1/2/3/5/7/10 Min) die **volle** CSV-Vorlage nutzen — die interaktive
`--manual`-Eingabe und die kurze `--template`-Vorlage decken nur das
schnellere 4-Punkt-Morgenprotokoll ab (HR-only, kein Blutdruck):

```bash
python3 scripts/importers/import_orthostatic_manual.py --template-full > mein_test.csv
# mein_test.csv ausfüllen, dann:
python3 scripts/importers/import_orthostatic_manual.py --file mein_test.csv
```

```bash
python3 scripts/analysis/cardiovascular/analyse_orthostatic.py
```
